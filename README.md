
# Athlete Program Dashboard

This repository contains the frontend task I completed as part of a hiring assignment for a Frontend Developer role.

Live demo: https://athlete-program-dashboard.vercel.app/

Status: Completed — this task was finished in full.

## Overview

The project is a responsive dashboard built with modern frontend tooling. It demonstrates UI composition, component-driven design, and responsive layout using a React/Next.js stack.

## Features

- Responsive layout and navigation
- Custom components and reusable UI elements
- Accessible and semantic markup where applicable
- Styled with Tailwind CSS and utility-first approaches

## Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript

## Getting Started (Local)

1. Install dependencies:

   ```bash
   cd Client
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open `http://localhost:3000` in your browser.
